Measure Catalog

The Measure Catalog documents how business knowledge is encoded into the NorthStar semantic layer. Measures are organized as an architecture, from physical aggregations up through the four executive indexes, rather than as an inventory. Internal helper measures are intentionally omitted.

Like an API reference, this catalog documents the semantic architecture a developer would build from, not every private measure. The page teaches the framework: how a stored column climbs through base measures, KPIs, normalized scores, and pillars into GPI, OPI, VPI, and finally PHI. The measure tables at the end are a deliberately short, structural sample.

The recursive architecture

Every measure sits on one of ten layers. Each layer consumes the one above and is consumed by the one below. This recursion, from a stored column all the way to an executive insight, is the design that defines NorthStar.

The index framework

Four composite indexes sit at the top of the model. GPI, OPI, and VPI each score one performance domain, and all three roll up into PHI, the single portfolio number. Each index is a weighted blend of its own pillar scores.

Design principles

The rules that keep the architecture maintainable. They are enforced by the layering itself.

Base measures are written onceEvery ratio and score reuses a base aggregation. A column is never summed twice in two places.
Business logic lives below presentationPresentation measures consume scores; they never compute a KPI. A color reads a tier, it does not recalculate it.
Indexes reference pillars, not displayAn index rolls up its pillar scores. It never reads a color, icon, or formatted string.
Scores are rescaled before they combineUnlike metrics are normalized to a common 0–100 basis before they are weighted together.
Every index resolves to PHIGPI, OPI, and VPI each roll up into the one portfolio number, so every measure has a path to the executive score.
Variables over nested expressionsHeavy measures resolve each input into a variable once, then combine them. Nothing recomputes inside an iterator.
