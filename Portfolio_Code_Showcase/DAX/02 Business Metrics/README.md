# 02 Business Metrics

Cost, conversion and the forward-looking windows. Where business rules enter the model.

Read in file order — each measure builds on the ones before it.

- **`01_Cost_per_Lead_Actual.dax`** — Spend over recorded leads.
- **`02_Cost_per_Visit_Actual.dax`** — Spend over visits.
- **`03_Cost_per_Lease_Actual.dax`** — Spend over signed leases.
- **`04_Cost_per_Click.dax`** — Spend over clicks.
- **`05_CTR.dax`** — Clicks over impressions.
- **`06_Click_to_Visit.dax`** — Clicks that become visits.
- **`07_Visit_to_Lead.dax`** — Visits that become leads.
- **`08_Lead_to_Lease_Funnel.dax`** — Funnel throughput end to end.
- **`09_Sell_Rate.dax`** — Leases against available inventory.
- **`10_Touchpoints.dax`** — Interactions across a journey.
- **`11_Move_Ins.dax`** — Move-ins recorded.
- **`12_Move_Outs.dax`** — Move-outs recorded.
- **`13_Lease_Expirations.dax`** — Leases ending in the period.
- **`14_Scheduled_Move_Ins.dax`** — Committed future arrivals.
- **`15_Lease_Expirations_Next_60D.dax`** — Forward expiry volume.
- **`16_Scheduled_Move_Ins_Next_60D.dax`** — Forward committed arrivals.
- **`17_Move_In_Coverage_Ratio_60D.dax`** — Committed arrivals over known departures.
- **`18_New_Leases_Last_30D.dax`** — Trailing lease pace.
- **`19_Vacancy_Fill_30D.dax`** — How quickly vacancy is absorbed.
- **`20_Absorption_Days_Est.dax`** — Days to absorb current vacancy at recent pace.
