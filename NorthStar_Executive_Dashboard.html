Executive Dashboard

When this page says dashboard, it means the screen leadership actually uses. Not a page of reports, but the last layer of everything else in this portal: the data, the semantic model, and the Executive Decision Framework, all arriving as something an executive can read in a glance.

01

A different starting point

Most executive dashboards focus on presenting information. NorthStar focuses on helping executives make decisions.

Most executive reporting struggles with the same problems. Metrics become disconnected. Priorities get lost. Reports explain what already happened instead of what needs attention next. Adding more charts to that pile does not help. It just adds more to read.

NorthStar starts from a different assumption. A screen for executives should be judged by the decisions it leads to, not the data it shows. Everything else follows from that. Metrics roll up into indexes. Reporting points forward, not just backward. Priority is stated, not implied. And when signals disagree, the page resolves them into one read you can defend.

02

Start with the decision

Visualization is not the design objective. Decision support is. Every visual therefore exists only where it advances a specific executive judgment.

Most dashboards get built from the chart menu outward. A card here, a map there, a table because there was room. It looks thorough and decides nothing.

NorthStar works the other way. It starts with the decision that needs to be made, then works backward to the visual. Every element on the page is there because it helps answer a specific executive question. The bullet comparing portfolio health to its target is there because someone has to decide whether the portfolio is on plan. The occupancy and cost-per-lease trends are there because the direction of travel changes the call. If a visual does not improve a decision, it does not belong.

03

The last layer

What executives see is only the final layer of NorthStar. Behind every score is a semantic model. Behind the semantic model is a warehouse. Behind the warehouse is the synthetic operating environment. The screen is simple on purpose, because everything complicated has already happened before the page loads.

Every other document in this portal describes one of those layers. This one describes the only layer built to be used every day.

05

The visual language

One rule runs through the whole interface: each kind of visual answers exactly one kind of question.

Cards tell you the current state. Trends tell you the direction. Comparisons tell you what matters most. Quadrants tell you what to do. Ask a single visual to do two of these jobs and it does neither one clearly, so nothing here is asked to.

Visual
Answers
Why
Cards
What changed?
One value or one sentence you can read in a second. Is this healthy right now, or not?
Trends
Which way is it moving?
A line over time, because the direction often matters more than today's number.
Scatter and bullet
Where do I look, and against what?
Position against peers or against a target, to find the outliers worth a closer look.
Quadrants
What do I do about it?
A two-by-two that turns a position into an action: scale, optimize, hold, or cut.
Action strips
What is next?
A short ranked list in plain words, so the page ends on a decision instead of a chart.
Maps
Where is it?
Geography, but only when the answer is literally a place. It lives on the index pages, not here.
06

How an executive moves through it

The pages are arranged as a hierarchy, not a gallery, so there is one path through them and it is the same every time. You do not browse NorthStar. You run it. Start at the portfolio number, follow it down to the discipline that is dragging, and end on the specific thing to do. A report lets you wander. This does not.

07

How it was designed to be read

The Framework pages are about how to think. This page is about how to read.

Executives read the way everyone reads when they are busy: fast, in pieces, looking for the next thing to do. So the interface was built for that, not for completeness. A few principles do most of the work.

Show the big thing first

The portfolio number comes first. Detail is one step away, not spread across the screen.

Order by decision

The page is arranged by what you need to decide first, not by what data happens to exist.

Keep it light

Each screen holds only a few things at once, so your attention goes to the call, not the layout.

Make the path obvious

Every step down has a reason attached, so the route itself tells you why you are taking it.

One question per visual

Nothing on the page tries to answer two things. A visual that does answers neither one well.

Always a way down

Every high-level signal has a defined path to its cause, so any read can be explained.

What this layer is

The executive summary answers four executive questions in under sixty seconds. It is not a report about the business. It is the interface through which the business is run.

NorthStar was never meant to turn executives into analysts. It was meant to cut the amount of analysis they have to do before they can decide with confidence. The framework says why the indexes exist. The guides say how to read each one. This page is where that understanding turns into a decision. It comes last because it is the only layer anyone in leadership actually touches, and everything under it exists so that this part can stay simple.

Good executive interfaces do not eliminate complexity. They absorb it.
